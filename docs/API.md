# HTTP API — PocketBridge v3.7

Локальный HTTPS-сервер запускается на порту `8765` (настраивается в диапазоне `1024–65000`; при занятости пробуются следующие 15 портов). Принимаются подключения только из локальных сетей (loopback, RFC 1918, CGNAT `100.64.0.0/10`, IPv6 ULA и link-local).

## Авторизация

- Все запросы к `/api/*` требуют заголовок:
  ```http
  X-Access-Key: <код с экрана телефона>
  ```
  При неверном или отсутствующем ключе возвращается `403 Forbidden`.
- `GET /` (веб-интерфейс) доступен без ключа; автоматический вход по ссылке `/#k=<код>` выполняется на стороне браузера.
- `GET /thumb` авторизуется параметром `?token=<сессионный токен>` (выдаётся через `POST /api/session`).
- `GET /preview` и `GET /dl` авторизуются одноцелевыми временными тикетами `?ticket=<id>` (TTL 10 минут).
- `/dav/*` использует стандартную HTTP Basic-авторизацию (логин любой, пароль — код доступа); `OPTIONS /dav/` открыт без авторизации для совместимости с клиентами ОС.

## Просмотр каталогов и поиск

### `GET /api/list?path=/`
Возвращает содержимое каталога (папки идут первыми; временные `.wifi-upload-*.part` скрыты).

```json
{
  "path": "/",
  "totalBytes": 128000000000,
  "freeBytes": 54200000000,
  "items": [
    {"name": "Фото", "path": "/Фото", "dir": true, "size": 0, "modified": 1731798000000},
    {"name": "заметки.md", "path": "/заметки.md", "dir": false, "size": 2048, "modified": 1731798720000}
  ]
}
```

### `GET /api/search?path=/&q=текст`
Рекурсивный поиск по подпапкам начиная с `path` (минимум 2 символа, NFC-нормализация, без обхода симлинков; лимит — 200 результатов, 20 000 узлов или 8 секунд).

```json
{"items": [...], "truncated": false}
```

### `GET /api/size?path=/Фото`
Подсчитывает суммарный размер файлов в каталоге (лимит — 200 000 узлов или 30 секунд).

```json
{"bytes": 15420912, "partial": false}
```

## Управление файлами и папками

### `POST /api/mkdir?path=/&name=Новая`
Создаёт папку внутри `path`. При конфликте имени — `409 Conflict`.

### `POST /api/mkdirs?path=/Фото/2026/Отпуск`
Рекурсивно создаёт цепочку вложенных папок (идемпотентно). Если сегмент занят файлом — `409 Conflict`.

### `POST /api/rename?path=/старое.txt&name=новое.txt`
Переименовывает файл или папку в пределах текущего каталога (`name` без `/` и `\`, до 200 символов). При занятом имени — `409 Conflict`.

### `POST /api/delete?path=/файл.txt`
Удаляет файл или папку со всем содержимым (симлинки удаляются как ссылки, без захода внутрь; корень `/` удалить нельзя).

## Скачивание и ZIP-архивы

### `POST /api/download-ticket?path=/файл.bin`
Выдаёт временную ссылку для потокового скачивания браузером:
```json
{"url": "/dl?ticket=<id>"}
```

### `POST /api/zip-ticket?base=/`
Тело запроса (`application/json`):
```json
{"paths": ["/Фото", "/Документы/отчёт.docx"]}
```
Выдаёт `{"url": "/dl?ticket=<id>"}` для потокового скачивания ZIP-архива с сохранением структуры относительно `base`.

### `GET /dl?ticket=<id>`
Отдаёт файл (`Content-Disposition: attachment`, с поддержкой `Range` → `206 Partial Content` / `416 Range Not Satisfiable`) или потоковый ZIP (`Transfer-Encoding: chunked`). Принимает только тикеты типов `download` и `zip`.

### `GET /api/download?path=/файл.bin` и `POST /api/download-zip?base=/`
Прямое скачивание файла (с поддержкой `Range`) и потокового ZIP с заголовком `X-Access-Key`.

## Загрузка файлов и докачка

### `POST /api/upload-init?path=/&name=video.mp4&size=104857600&overwrite=0&unique=0`
Открывает сессию чанковой загрузки (до 20 ГБ):
- `overwrite=1` — разрешить замену существующего файла;
- `unique=1` — автоматически подобрать свободное имя `video (1).mp4`;
- иначе при совпадении имени возвращается `409 Conflict`.

```json
{"uploadId": "<id>", "name": "video.mp4", "chunk": 4194304, "received": 0}
```

### `GET /api/upload-status?id=<uploadId>`
Возвращает текущее состояние незавершённой загрузки для возобновления после паузы или обрыва сети:
```json
{"uploadId": "<id>", "name": "video.mp4", "received": 8388608, "size": 104857600}
```

### `POST /api/upload-chunk?id=<uploadId>&offset=<received>`
Тело запроса — сырые байты очередной части (от 1 байта до 32 МБ) с `Content-Length`.
- Ответ `200 OK`: `{"received": 12582912, "size": 104857600}`.
- При несовпадении `offset` — `409 Conflict` с заголовком `X-Upload-Received: <актуальное смещение>`.

### `POST /api/upload-finish?id=<uploadId>`
Атомарно переименовывает временный `.part`-файл в целевой, если `received == size`. Ответ: `{"ok": true, "name": "video.mp4", "size": 104857600}`.

### `POST /api/upload-abort?id=<uploadId>`
Отменяет загрузку и удаляет временный `.part`-файл.

### `POST /api/upload?path=/&name=file.txt&overwrite=0&unique=0`
Однозапросная загрузка сырого тела файла с `Content-Length` (до 20 ГБ) через временный `.part`-файл.

## Предпросмотр и миниатюры

### `POST /api/session`
Выдаёт сессионный токен для загрузки миниатюр:
```json
{"token": "<32 hex>", "ttl": 7200000}
```

### `GET /thumb?token=<token>&path=/Фото/img.jpg&w=320`
- Для растровых изображений и видео возвращает `image/jpeg` (ширина ограничена 64–512 px, кешируется на диске до 200 МБ).
- Для `.svg` (до 5 МБ) возвращает `image/svg+xml` с `Content-Security-Policy: default-src 'none'; ...; sandbox`.

### `POST /api/preview-ticket?path=/Фото/img.jpg` → `GET /preview?ticket=<id>`
Выдаёт `{"url": "/preview?ticket=<id>", "mime": "..."}` для inline-просмотра изображений, SVG (до 5 МБ, с `sandbox` CSP), аудио, видео и PDF (с поддержкой `Range`). Форматы HEIC/RAW (`.heic/.heif/.dng/.cr2/.nef/.arw/.raf`, до 50 МБ) перекодируются на лету в JPEG (до 2400 px, качество 82). Тикеты `preview` действительны только для `/preview`.

### `GET /api/text?path=/заметки.md`
Возвращает UTF-8 текст для `.txt`, `.md`, `.csv`, `.log`, `.json`, `.xml`, `.html`, `.htm`, `.css`, `.js` размером до 5 МБ.

### `GET /api/docx?path=/отчёт.docx`
Извлекает текст из `word/document.xml` (до 8 МБ XML, до 1 000 000 символов, документы с DTD отклоняются):
```json
{"text": "...", "truncated": false}
```

## WebDAV (`/dav`)

Поддерживаются методы `OPTIONS`, `PROPFIND` (`Depth: 0` и `Depth: 1`), `GET` (включая `Range`), `HEAD`, `PUT` (`Content-Length` и `Transfer-Encoding: chunked`, до 20 ГБ), `MKCOL`, `DELETE`, `MOVE`, `COPY` (с заголовком `Overwrite: T|F`), `PROPPATCH`, `LOCK`, `UNLOCK`. Подробнее — в [WEBDAV.md](WEBDAV.md).

## Лимиты

| Параметр | Значение |
| --- | --- |
| Параллельные рабочие потоки | до 32 (при переполнении — `503`) |
| Сессии `/thumb` | до 16 активных, TTL 2 часа |
| Тикеты `/preview` и `/dl` | до 256 активных, TTL 10 минут |
| Одновременные чанковые загрузки | до 32, TTL 6 часов, чанк до 32 МБ |
| Максимальный размер загружаемого файла | 20 ГБ |
| Кеш миниатюр | 200 МБ (автоочистка старейших файлов) |
| Превью HEIC/RAW / текста и SVG / DOCX XML | 50 МБ / 5 МБ / 8 МБ |
| ZIP-архив | до 500 выбранных объектов, до 5 000 файлов, глубина до 40 |
