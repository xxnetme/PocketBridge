# API PocketBridge v3.0

Локальный HTTP/HTTPS сервер на порту 8765 (по умолчанию). Все запросы требуют кода доступа, за исключением авторизации.

## Сессия

### POST /api/session
Создаёт сессию и возвращает токен.

**Запрос:** `{}`

**Ответ:**
```json
{"token": "<токен на 2 часа>"}
```

Токен используется в заголовке `Authorization: Bearer <token>` или параметром `?token=<token>` для доступа к миниатюрам.

---

## Файлы

### GET /api/list?path=/&session=<token>
Список файлов и папок в указанном каталоге.

**Ответ:**
```json
{"items": [
  {"name": "фото.jpg", "type": "file", "size": 2430000, "modified": 1731798720000},
  {"name": "Отпуск", "type": "dir", "size": null, "modified": 1731798000000}
]}
```

### GET /api/download?path=/файл.jpg&session=<token>
Скачивание файла. Поддерживает `Range`-заголовок для докачки.

### POST /api/upload
Загрузка файла (multipart/form-data). Поддерживает докачку больших файлов чанками.

### DELETE /api/delete?path=/файл.jpg&session=<token>
Удаление файла или папки.

### POST /api/mkdirs?path=/новая/папка&session=<token>
Создание вложенных каталогов.

### POST /api/search?q=текст&session=<token>
Поиск файлов по подпапкам (до 200 результатов, 8 секунд).

## Просмотр

### POST /api/preview-ticket?path=/файл.jpg&session=<token>
Временно ссылка для просмотра файла в браузере.

**Ответ:**
```json
{"url": "/preview?ticket=<билет>", "mime": "image/jpeg"}
```

Срок действия билета — 10 минут.

### GET /preview?ticket=<билет>
Отдаёт содержимое файла для inline-просмотра (изображение, PDF, текст).

### GET /thumb?token=<токен>&path=/фото.jpg&w=320
Миниатюра изображения. Ширина по умолчанию 320 px. Кешируется на диске.

## HEIC / RAW (v3.0)

Форматы `.heic/.heif/.dng/.cr2/.nef/.arw/.raf` не поддерживаются браузерами нативно. При запросе `preview-ticket` сервер:

1. Определяет MIME по расширению (`image/x-adobe-dng`, `image/x-canon-cr2`, `image/x-nikon-nef`, `image/x-sony-arw`, `image/x-fuji-raf`, `image/heic`).
2. Перекодирует в JPEG через `Thumbnails.previewJpeg()` (ширина до 2400 px, качество 82).
3. Отдаёт JPEG по `/preview?ticket=…`.

Полный файл при скачивании остаётся в исходном формате.

## WebDAV

### GET /dav
Веб-DAV совместимый список файлов для Windows File Explorer и macOS Finder.

**Требует ручной проверки** на реальных устройствах (не тестируется в песочнице).

---

## Ограничения

- Сессии: максимум 16 активных, срок жизни 2 часа.
- Билеты превью: максимум 256, срок жизни 10 минут.
- Кеш миниатюр: лимит 200 МБ, удаление старейших (FIFO).
- Текстовые файлы просмотра: до 5 МБ.
- ZIP: до 500 файлов за раз.
- Загрузка: до 20 ГБ на файл.
