# PocketBridge 4.9.0 — как проверить кандидата

Тестовый кандидат с номером будущего выпуска (`versionCode 29`). Не официальный релиз. Функции не требуют аккаунта, облака, расширения или программы для ПК. Внешние сертификаты и сервисы для хеширования не нужны. Сюда не входят 4.2 (докачка скачиваний **телефон → ПК**) и функции v5–v9.

| Функция | Где найти | Что важно |
| --- | --- | --- |
| **4.1 · Докачка загрузок** | **Загрузить** → **Передачи**. После перезапуска — войдите с действующим кодом и нажмите **Выбрать файл** у черновика. | Тот же адрес с портом, профиль браузера и общая папка. Выберите исходный файл: сервер использует только подтверждённые байты, браузер сверяет SHA‑256. Передача не продолжается в закрытой вкладке. **Пауза** оставляет черновик, **Отмена** запрашивает его удаление на телефоне. |
| **4.3 · Корзина** | **Корзина** рядом с поиском. Действует для удаления из браузера и команды WebDAV `DELETE`. | Можно указать другое имя или папку в общей области. Восстановление не перезаписывает существующий объект. **Удалить навсегда** требует подтверждения. |
| **4.4 · Большие папки / телефон** | Страницы списка и плитки, переход по номеру, меню `⋯` у объекта на телефоне. | До 120 отрисованных записей на страницу. Поиск по имени смотрит всю открытую папку. Выделение сохраняется при перелистывании; «Выделить все видимые» относится к текущей странице. |
| **4.5 · Пакетное переименование** | Выделите 2–200 объектов → **Переименовать группой** → **Предпросмотр** → **Применить**. | Например `Фото_{n:3}{ext}` → `Фото_001.jpg`. Коллизии видны в предпросмотре; коллизии после него показываются как частичный результат. Перестановки занятых имён по циклу не делаются. |
| **4.6 · Точный поиск** | **Точный поиск**, затем имя (необязательно), даты, размер в МиБ и тип / расширение. | Даты определяются по часовому поясу браузера и включают весь указанный последний день. Фильтры сохраняются в данном браузере. Сканирование не выходит за общую папку. Если результат ограничен, уточните запрос. |
| **4.7 · Проверка папки** | В папке: **Проверка папки** → **Рассчитать SHA-256**. Укажите путь ко второй папке или экспортируйте/импортируйте JSON-отчёт для другой копии. | Сравнение по относительному пути и SHA‑256: совпало, изменилось, отсутствует, добавлено. Проверяются файлы, не пустые каталоги; ссылки пропускаются. Если файлы другие приложения меняют одновременно, повторите проверку без изменений. |
| **4.8 · Дубликаты** | **Поиск дублей** → **Найти совпадения** → отметьте лишние копии → подтверждение **Переместить в корзину**. | Группировка по фактическому содержимому. Ничего автоматически не удаляется. Нужно оставить хотя бы одну проверенную копию каждой группы. |
| **4.9 · Профили доступа** | Android → **Настройки**: выберите общую папку и режим → **Профили доступа** → **Сохранить текущие**. Для переключения нажмите профиль → **Применить**. | Например, сохраните «Фото» с режимом «Только чтение» и «Загрузки» с записью. Применение закрывает прежнее подключение, при работающем доступе выдаёт новый код. Недоступный профиль нельзя применить; полный корень не подставляется. |

## Хранение и ограничения

- **Черновики:** один файл до 20 ГиБ, чанки 4 МиБ, до 32 активных, общий лимит 20 ГиБ и запас свободного места 32 МиБ. Через 24 часа без подтверждённых частей черновик истекает. Очистка при запуске и периодически, пока включён доступ с записью к этому же корню. В IndexedDB только описание и хеш, без содержимого файла и кода. Если очистить сайт или поменять адрес, очередь там не восстановится. Загрузка дерева папок и WebDAV `PUT` не получают постоянной докачки.
- **Корзина:** до 7 дней, 20 ГиБ и 512 объектов на корень. Переполнение не удаляет свежие объекты и не уничтожает исходник. Корзина не резервная копия и не сохраняет прежние версии при перезаписи.
- **Отчёты:** один запущенный поиск по содержимому; до 20 000 файлов, 128 ГиБ чтения и 20 минут. Сохраните JSON, если отчёт должен пережить перезапуск. В режиме «Только чтение» поиск, сравнение и поиск дублей доступны, но корзина, переносы и загрузка заблокированы.
- **Системные границы:** не изменяйте скрытые каталоги `.pocketbridge-uploads` и `.pocketbridge-trash` файловым менеджером телефона. При параллельных изменениях другими приложениями сделайте новый предпросмотр/отчёт. Удаление между разными томами с необратимым копированием не используется.

Точные параметры API: [API.md](API.md) · [WebDAV](WEBDAV.md).

## Проверки

- `PB_TEST_LARGE=1 ./server-tests/run.sh` — JVM/HTTPS/WebDAV, включая потерянные подтверждения, смену ключа/корня, коллизии и потоковый отчёт для разреженного файла >5 ГиБ. Регрессии RC2 проверяют SAN с обязательной проверкой имени TLS, ссылки WebDAV, сохранение токенов при заполнении таблицы и конкуренцию за последний эфемерный слот.
- `node server-tests/features-ui-test.js` (Playwright + JDK) — реальный HTTPS, перезапуск сервера и вкладки, исходник того же размера с другими байтами, пауза и ручной повтор без повторной отправки подтверждённых байтов, неуспешная отмена с повтором, смена имени при финальной коллизии, удалённый черновик без автоматического старта. Проверяются инструменты папки, выделение на разных страницах и 10 000 записей на экране 360 px. `ui-test.js` — регрессия прежнего интерфейса.
- `./gradlew lintDebug assembleDebug testDebugUnitTest` — сборка и проверки Android: переключение профиля, отказ для пропавшей папки и отмена запуска во время подготовки TLS. Новые проверки запуска подтверждают, что путь общей папки проверяется в фоне до и после TLS, а отменённый запуск, отозванное разрешение и устаревший профиль не открывают доступ.

Перед стабильным выпуском проверьте на физических Android 10/15/16: фон/убийство процесса, FUSE и свободное место, переоткрытие HTTPS с актуальным кодом, `DELETE` из клиента ОС, переключение профиля из приложения и повторное подключение. Локальная debug-подпись не обеспечивает установку поверх опубликованной версии — см. [правила релиза](RELEASE.md).
