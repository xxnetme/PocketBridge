# Чек-лист WebDAV — PocketBridge v3.0

PocketBridge предоставляет WebDAV-совместимый endpoint по адресу:

```
https://<IP-телефона>:8765/dav
```

## Windows File Explorer

1. Откройте «Этот компьютер».
2. В верхней панели нажмите «Добавить сетевое расположение».
3. Выберите «Настраиваемое сетевое расположение».
4. Введите адрес: `https://<IP-телефона>:8765/dav`
5. Введите код доступа, показанный на экране телефона.
6. При предупреждении о сертификате — подтвердите исключение (сертификат самоподписанный).

**Что проверить:**
- [ ] Подключение устанавливается без ошибок
- [ ] Список файлов отображается корректно
- [ ] Открытие файла (двойной клик) работает
- [ ] Копирование файла с телефона на компьютер работает
- [ ] Копирование файла с компьютера на телефон работает
- [ ] Удаление файла работает
- [ ] Создание новой папки работает

## macOS Finder

1. Откройте Finder.
2. Нажмите ⌘+K (или «Переход» → «Подключение к серверу»).
3. Введите адрес: `https://<IP-телефона>:8765/dav`
4. Нажмите «Подключиться».
5. При предупреждении о сертификате — подтвердите исключение.
6. Введите код доступа.

**Что проверить:**
- [ ] Подключение устанавливается без ошибок
- [ ] Список файлов отображается корректно
- [ ] Открытие файла работает
- [ ] Копирование файла в обе стороны работает
- [ ] Удаление файла работает
- [ ] Создание новой папки работает

## Ограничения

- Сертификат самоподписанный — браузер/ОС может要求ть подтверждение исключения.
- Для постоянного доверия сертификат нужно импортировать в доверенные корневые центры.
- WebDAV не тестируется в песочнице — проверка требуется на реальных устройствах Windows и macOS.

## Устранение проблем

| Проблема | Решение |
|---|---|
| Не удаётся подключиться | Проверьте, что телефон и компьютер в одной сети Wi-Fi. Убедитесь, что сервер запущен на телефоне. |
| Ошибка сертификата | Подтвердите исключение в браузере один раз. Для Explorer/Finder может потребоваться импорт сертификата. |
| Файлы не отображаются | Проверьте права доступа к хранилищу на телефоне (Android 11+ требует доступа ко всем файлам). |
| Медленная работа | Используйте локальную сеть Wi-Fi 5 ГГц для лучшей скорости. |
