# PocketBridge v4.0.1 — проверка на Android

Проверка подписи APK и тесты Robolectric не подтверждают установку поверх на Android. Эмулятор с настоящим Android Package Manager подтверждает обновление на выбранном API, но не заменяет телефон для фоновой работы, точки доступа и multicast.

## Установка поверх и сохранение настроек

Соберите пару из тега `v4.0` и проверяемого коммита `v4.0.1` **с одним временным ключом**, не с ключами опубликованных debug-APK. Нужны Git, SDK 36, JDK 21, Python 3.11+ и `adb` из Android Platform Tools. Работайте из репозитория с тегом `v4.0` и закоммиченным кандидатом в `HEAD`:

```bash
tools/build-upgrade-pair.sh v4.0 ./upgrade-qa
adb devices -l
python3 tools/verify-update.py --serial <серийный-номер> \
  upgrade-qa/previous.apk upgrade-qa/candidate.apk
```

Только для чистого эмулятора или запасного телефона, где **нет** PocketBridge. Скрипт не удаляет установленное приложение и откажется работать, если найдёт его. Оба APK экспериментальные; их не публикуют. Проверка меняет язык интерфейса, убеждается, что выбор пережил перезапуск, выполняет `adb install -r` и проверяет новый номер версии и сохранённый язык. Успех `apksigner` без `adb install -r` не считается прохождением проверки.

Для расширенной ручной проверки начните с чистого устройства: до обновления задайте нестандартный порт (`8877`), выберите отдельную тестовую общую папку, включите «Только чтение» и mDNS, задайте автостоп и язык. Сохраните их значения. Обновите приложение без удаления через установщик или `adb install -r`, откройте настройки и сверьте их. Запустите сервер, проверьте прежнюю папку, новый код доступа и запрет записи в браузере и WebDAV. Активные передачи, код старой сессии и содержимое буфера в памяти не входят в проверку сохранения настроек.

## Матрица для телефонов

Запишите модель, версию Android/прошивки, версию приложения и статус каждой проверки. Начните с Android 10 (API 29 — обычное разрешение хранилища) и Android 15/16 (API 35/36 — «Доступ ко всем файлам», уведомления и ограничения фонового запуска). Используйте только тестовые файлы в отдельной папке.

| Сценарий | Что считать успехом | Android 10 | Android 15 | Android 16 |
| --- | --- | --- | --- | --- |
| Установка поверх | Пакет обновлён без удаления; язык, порт, папка и режим доступа не сброшены | Не запускалось на телефоне | Не запускалось | Не запускалось |
| Плитка | Добавление вручную, на 13+ также из настроек приложения. Запуск/стоп, состояние плитки и сервера совпадают; при блокировке сначала разблокировка | Не запускалось | Не запускалось | Не запускалось |
| «Поделиться» | Галерея: одно фото. Файловый менеджер: несколько файлов. Подтверждение добавляет файлы в Inbox без перезаписи; отмена ничего не добавляет. Текст при активном сервере появляется в буфере, без сервера — в Inbox без запуска доступа | Не запускалось | Не запускалось | Не запускалось |
| Передача с погашенным экраном | Выключите «Не гасить экран» и начните большую передачу с ПК. Погасите экран минимум на 2 минуты. Передача завершается без перезапуска; SHA‑256 файла на стороне получателя совпадает | Не запускалось | Не запускалось | Не запускалось |
| Точка доступа | ПК подключён к hotspot телефона без интернета; открываются браузер и WebDAV по адресу и фактическому порту телефона, проверено скачивание | Не запускалось | Не запускалось | Не запускалось |
| mDNS | В той же сети с включённым mDNS клиент DNS‑SD на ПК видит `_https._tcp`, разрешает экземпляр PocketBridge и получает фактический порт; после остановки доступ прекращается | Не запускалось | Не запускалось | Не запускалось |

Для mDNS на macOS: `dns-sd -B _https._tcp local.` и `dns-sd -L '<имя из списка>' _https._tcp local.`. На Linux с Avahi: `avahi-browse -rt _https._tcp`. Фиксированного `pocketbridge.local` тест не предполагает.

## Результаты автоматических проверок

- **Установка поверх на эмуляторе Android 10 (API 29) — прошла.** Две непубликуемые APK с одним временным ключом: `4.0` (`25`) → `4.0.1` (`26`). В данных старой версии подготовили шесть нестандартных значений: RU, порт `8877`, папку `Download`, «Только чтение», mDNS и автостоп 15 минут. `adb install --no-streaming -r` без root вернул `Success`, Package Manager показал `4.0.1` / `26`, SHA‑256 файла `pb-settings.xml` не изменился. Root в чистом эмуляторе использован только для записи и чтения фикстуры, не для установки. Полный UI-сценарий на этом медленном эмуляторе без KVM не завершился в лимит; выше — результат отдельной проверки установки и файла настроек.
- **Android Lint, сборка debug и 10 тестов Robolectric — прошли.** В том числе версия на экране, старый и текущий отчёт о сбое, обработка входящих Share и запуск через плитку в тестовом окружении. Это не проверки на телефоне.
- **Подпись — прошла с временным ключом.** 13 автономных тестов правил выпуска. Реальные APK/AAB прошли проверку пакета, версии, сертификата и SHA‑256; этап подготовки артефактов отказался принимать отсутствующий ключ, неверный отпечаток, debug-APK, несовместимого подписанта и AAB с неподписанной добавленной записью.
- **Сервер и WebDAV — 316 проверок, 0 ошибок.** Локальный Playwright по HTTPS — 102 из 103: в эмуляции iPhone 13 строка кнопок файла занимает 48 px при пределе теста 32 px. Тот же результат воспроизвёлся с исходниками тега `v4.0` в том же Chromium; веб-код не менялся.

Для тега и ручного запуска GitHub Actions настроена отдельная UI-проверка обновления на эмуляторах API 29 и API 36. Новый workflow ещё не запускался в GitHub. Матрица выше относится только к физическим телефонам.
