# CHANGELOG

## 1.7 — 17.11.2026

Релиз по плану обновлений: безопасность (v1.7), работа с файлами (v1.8) и полировка (v1.9).

### Безопасность
- **HTTPS с самоподписанным сертификатом.** Сертификат и ключ (RSA-2048, срок 2 года) генерируются на телефоне при первом запуске (`SelfSignedCertificate.java`, кодирование X.509/DER без внешних библиотек) и хранятся в приватном каталоге. Раньше код и файлы шли открытым текстом.
- **Кнопка «Сменить код»** — новый код без перезапуска приложения.
- **Автостоп после 30 минут без подключений** (`ServerService.IDLE_LIMIT_MS`) — забытый сервер не остаётся открытым навсегда.
- **Ссылка с кодом** `https://<ip>:<port>/#k=<код>`: копируется с телефона одной кнопкой и входит в браузере автоматически (фрагмент сразу стирается из адресной строки).
- Срок жизни ссылок превью сокращён с 30 до 10 минут.
- Текст «Защищённый доступ по коду» заменён на «Доступ по коду в локальной сети» — обещание «защищённости» больше не вводит в заблуждение, плюс в интерфейсе появилось объяснение про сертификат.

### Файлы
- **ZIP со структурой папок:** записи архива сохраняют вложенность (`Фото/Отпуск/IMG_2000.jpg`), одинаковые имена из разных папок больше не конфликтуют.
- **Скачивание папки целиком в ZIP** — кнопка «ZIP» в строке папки.
- **Поиск по всем вложенным папкам** — переключатель «искать здесь / искать везде», результаты показывают путь и не мешают навигации. Лимиты: 200 результатов, 20 000 просмотренных записей, 8 секунд.
- **Перетаскивание файлов** из проводника в окно браузера.
- Архивирование папок с файлами в списке выбора (раньше папки в ZIP не допускались).

### Полировка
- Приложение называется **PocketBridge** (было «Файлы по Wi-Fi»), заголовок страницы — `PocketBridge · Файлы телефона`.
- **Лицензия MIT** (`LICENSE`).
- **Тесты переехали в репозиторий** (`server-tests/`): 75 проверок серверной части, включая TLS, поиск и структуру ZIP. Запуск: `./server-tests/run.sh` (JDK 17, без Android SDK).
- CI собирает APK и прогоняет серверные тесты.
- `targetSdk 34`, `versionCode 9`.

### Проверено
- `server-tests/run.sh` — **75/75** (HTTP, HTTPS/TLS, Range, ZIP-структура, поиск, лимиты, anti-DoS).
- Браузерные тесты (Chromium, HTTPS) — **42/42**, включая автологин по ссылке, глобальный поиск, ZIP папки, drag&drop, мобильную вёрстку.
- `./gradlew assembleDebug` — `BUILD SUCCESSFUL`, APK 63 КБ.

### Осталось (v1.8+)
- Локализация интерфейса (RU/EN), светлая тема, экран настроек (порт, таймаут автоостановки).
- Миниатюры фото в списке (декодирование на телефоне + кеш).
- QR-код: отложен — с телефона его некому сканировать; вместо него сделана ссылка с кодом.
- Подпись release-сборки и публикация артефакта в релизах GitHub.

## 1.6 — 17.11.2026

Обновление по итогам пользовательского тестирования v1.5 (см. `PocketBridge-review.md`).

### Исправлено

| # | Проблема в 1.5 | Что сделано |
|---|---|---|
| 1 | Сервер умирал при сворачивании/блокировке экрана | Новый `ServerService` (foreground service, тип `dataSync`): сервер живёт в фоне, в уведомлении виден код доступа и кнопка «Остановить». На Android 13+ запрашивается разрешение на уведомления |
| 2 | Файлы 1–2 ГБ роняли вкладку (весь файл в `blob()` в памяти) | Скачивание и ZIP идут через временную ссылку (`/api/download-ticket`, `/api/zip-ticket` → `/dl?ticket=…`): браузер сам стримит на диск. Ссылки одноразово-временные: 10 минут, без кода доступа |
| 3 | Нет докачки — обрыв на 90% означал качать заново | `Range` поддержан для `/api/download`, `/dl` и `/preview`: `206 Partial Content`, `Content-Range`, корректный `416` |
| 4 | 6 «молчащих» TCP-соединений вешали сервер до 2 минут | Пул переведён на `SynchronousQueue` до 32 потоков, таймаут на чтение заголовков — 15 с (тело запроса — до 10 мин), при переполнении честный `503` |
| 5 | Android 10 (API 29): пустой список из-за scoped storage | `android:requestLegacyExternalStorage="true"` |
| 6 | Нет иконки приложения | Adaptive icon из `assets/logo.svg` (vector drawable, API 26+) |
| 7 | Нет прогресса загрузки | Прогресс-бар с процентом и скоростью, кнопка «Отмена» (XHR `upload.onprogress` + `abort`) |
| 8 | Конфликт имён — тупик | Диалог: **Перезаписать / Сохранить как / Пропустить** (сервер: `overwrite=1`, `unique=1`; коды `409`) |
| 9 | Действия строки на телефоне за горизонтальным скроллом | Мобильная вёрстка карточками: имя, размер, дата и все действия в пределах экрана |
| 10 | Одна строка пути | Хлебные крошки `Телефон / Фото / Отпуск` — возврат в любой уровень одним кликом |
| 11 | `targetSdk 32` | `targetSdk 34` (требование Google Play), `versionCode 8`, `versionName 1.6` |
| 12 | В листинге видны брошенные `.part`-файлы | Временные `.wifi-upload-*.part` скрыты из списка |
| 13 | Ошибки 400 на любой конфликт | Отдельные коды: `409 Conflict`, `429 Too Many Requests`, `503 Service Unavailable` |

### Добавлено
- **Сортировка** по имени / размеру / дате / типу (папки всегда сверху).
- **Кнопка «Отмена»** для текущей загрузки.
- **Совместимость с CGNAT (100.64/10), IPv6 ULA и link-local** — приложение принимает запросы из таких сетей.
- **`FileServer.key()`**, `start/stop` через сервис — экран корректно показывает состояние после перезапуска.
- Экран больше не гаснет, пока сервер запущен (`FLAG_KEEP_SCREEN_ON`).

### Изменено
- Сервер больше не стартует/останавливается из Activity напрямую — только через `ServerService` (одно состояние на всё приложение).
- Лимит активных ссылок — 256 (было 128 только для превью).
- Тексты: «Работает, даже если свернуть приложение или заблокировать экран».

### Проверено
- `testbed/server-tests.log` — **76/76** (включая Range, overwrite/unique, zip-ticket, лимиты, anti-DoS).
- `testbed/ui-tests.log` — **38/38** пользовательских сценариев в Chromium (десктоп + iPhone-эмуляция).
- Сборка: `./gradlew assembleDebug` → `BUILD SUCCESSFUL` (JDK 17, Gradle 8.9, compileSdk 35).

### Осталось (следующие релизы)
- **HTTPS с самоподписанным сертификатом** — сейчас HTTP, код летит открытым текстом (главный риск в недоверенных сетях). Плюс не показывать «Защищённый доступ» на экране входа.
- ZIP с сохранением структуры папок (сейчас плоский, файлы с одинаковыми именами не скачать).
- Поиск по подпапкам, drag&drop, QR-код на экране телефона.
- Лицензия (MIT/Apache-2.0), единое имя (сейчас PocketBridge / «Файлы по Wi-Fi» / `com.local.wififiles`).
